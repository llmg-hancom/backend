# backend

## 폴더 구조

```
app
├── api                 # 라우터
│   └── v1              # 버전 1 API 라우터
├── core                # 주요 설정 관련 코드
├── db                  # 데이터베이스/ORM 설정 관련 코드
├── errors              # 서비스에서 발생하는 오류 클래스
├── models              # 데이터베이스 모델 클래스
├── schemas             # API 스키마 클래스
├── services            # 서비스 코드
└── utils               # 유틸리티 코드
```
